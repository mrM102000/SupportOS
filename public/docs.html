Quick Start

The fastest way to add AI support triage to any website — one script tag, no backend needed.

1. Generate an API key

Go to Admin → API Keys and create a new key. Copy the full key — it is only shown once.

2. Embed the widget

Add this tag to your site's <body> — the chat bubble appears instantly.

<!-- SupportOS Widget -->
<script
  src="http://localhost:3000/widget.js"
  data-key="sos_YOUR_API_KEY"
  data-title="How can we help?"
  data-color="#00d4aa"
></script>

3. Or call the API directly

fetch('http://localhost:3000/api/triage', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-Api-Key': 'sos_YOUR_API_KEY'
  },
  body: JSON.stringify({ message: 'I was charged twice' })
})
.then(r => r.json())
.then(data => console.log(data));

Authentication

All integration endpoints require an API key. Admin endpoints require a JWT token from POST /api/admin/login.

API Key — for widget and triage integrations

Pass your key in the X-Api-Key request header, or as ?api_key=sos_... in the query string. Keys start with sos_.

JWT Token — for admin API endpoints

Post to /api/admin/login with username/password. Use the returned token as Authorization: Bearer <token>. Expires in 24 hours.

Embeddable Widget

Drop one script tag on any page to add a fully-functional AI support chat widget. No React, no build step, no dependencies.

<script
  src="http://localhost:3000/widget.js"
  data-key="sos_YOUR_API_KEY"
  data-title="How can we help?"
  data-subtitle="AI-powered support — reply in seconds"
  data-color="#00d4aa"
  data-agent="SupportOS AI"
  data-position="right"

Webhooks

Configure a webhook URL in Admin → Settings to receive real-time POST notifications whenever a lead or audit request is submitted.

SupportOS sends a POST request with Content-Type: application/json to your configured URL within milliseconds of each event.

Webhook Payload

{
  "event": "audit.created",
  "timestamp": "2026-05-18T10:30:00.000Z",
  "data": {
    "id": "uuid",
    "name": "Jane Smith",
    "email": "jane@company.com",
    "company": "Acme Inc.",
    "helpdesk": "Zendesk",
    "weekly_tickets": "300–700",
    "status": "pending",
    "created_at": "2026-05-18T10:30:00.000Z"
  }
}
audit.createdA new audit request was submitted via the landing page form
lead.createdA new contact/lead was submitted via the contact form
test.pingTest event fired from Admin → Settings → Test Webhook

Signature Verification

If you set a webhook secret in Admin → Settings, every request includes an X-SupportOS-Signature header with your secret. Verify it to confirm the request came from SupportOS.

// Triage a customer message
async function triageMessage(message) {
  const res = await fetch('http://localhost:3000/api/triage', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-Api-Key': 'sos_YOUR_API_KEY'
    },
    body: JSON.stringify({ message })
  });
  const { data } = await res.json();
  console.log('Category:', data.triage.category);
  console.log('Route to:', data.routing.team);
  console.log('Reply:', data.suggested_reply);
  return data;
}

import requests

def triage_message(message):

        'http://localhost:3000/api/triage',

            'X-Api-Key': 'sos_YOUR_API_KEY',

// PHP — triage a message
function triageMessage($message) {
    $ch = curl_init();
    curl_setopt_array($ch, [
        CURLOPT_URL => 'http://localhost:3000/api/triage',
        CURLOPT_POST => true,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Content-Type: application/json',
            'X-Api-Key: sos_YOUR_API_KEY'
        ],
        CURLOPT_POSTFIELDS => json_encode(['message' => $message])
    ]);
    $result = json_decode(curl_exec($ch), true);
    curl_close($ch);
    return $result['data'];
}

Zendesk Integration

Use SupportOS triage before or after Zendesk ticket creation to auto-tag, route, and pre-draft responses.

// In your Zendesk webhook or app trigger
const triage = await triageMessage(ticket.description);

// Auto-tag the ticket
ticket.tags = [triage.triage.category, triage.triage.priority];

// Route to correct group
ticket.group_id = routingMap[triage.routing.team];

// Add internal note with CRM note
ticket.comment = { body: triage.crm_note, public: false };

// Draft a reply for the agent
ticket.comment = { body: triage.suggested_reply, public: true };

Intercom Integration

Triage incoming Intercom conversations and auto-assign to the right team with a pre-drafted reply.

// Intercom webhook handler
app.post('/intercom/webhook', async (req, res) => {
  const { body } = req.body.data.item;
  const triage = await triageMessage(body);

  // Assign conversation to correct team
  await intercom.conversations.assign({
    id: conversationId,
    team_id: teamMap[triage.routing.team]
  });

  // Add private note for agents
  await intercom.conversations.reply({
    id: conversationId,
    type: 'note',
    body: `[SupportOS] ${triage.crm_note}`
  });

  res.json({ ok: true });
});

Zapier / Make Integration

Use SupportOS webhooks as triggers in Zapier or Make to push new leads and audit requests into any tool — CRM, Slack, Notion, HubSpot.

Step 1: In Admin → Settings, enter your Zapier webhook URL (from a Zapier "Webhooks by Zapier" trigger) and enable webhooks.

Step 2: SupportOS will POST audit.created and lead.created events to that URL every time a form is submitted.

Step 3: In Zapier, map the payload fields (data.email, data.company, etc.) to HubSpot, Slack, Notion, or any other app.
